# 恐龙资料

dinosaurs.json 是图鉴和语音资料源。四十种恐龙各有两条短知识、一道双选观察题、正确索引和温和提示；题目不锁内容、不扣分。

知识已核对各记录 source 指向的伦敦自然历史博物馆资料。迅猛龙羽毛证据还核对了[美国自然历史博物馆](https://www.amnh.org/explore/news-blogs/velociraptor-feather-evidence)。棘龙游泳方式、剑龙背板用途保留不确定性；插画是特征辨识示意。文字是面向儿童的独立改写。

编辑后运行 `python3 tools/generate_dino_catalog.py`，重新生成字库和语音，再跑完整门禁。
