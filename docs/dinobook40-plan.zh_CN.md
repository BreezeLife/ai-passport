# 四十种恐龙实施计划

目标：完成四十种离线恐龙的生成动作、知识、猜题、语音和足迹，交付经过验证的固件。用户已授权全部四十种，取代之前的两样片提议；刷机、提交与发布仍需单独授权。

架构：保留应用/BSP 边界和知识闭环，从营地进入动作页。每种使用 Image 2 工作流生成八个动作姿态、复用 RGB565 缓冲、纯逻辑管理帧时序；动画放主应用，语音放独立资源分区。保留身份与 Recovery 预留，兼容旧八种存档。

## 分工与文件

- [x] 内容：知识 JSON、catalog 生成器/C、语音生成器/C 描述符与 `assets/audio/dinobook40/`。验证四十条有博物馆引用的资料，各两知识、一双选题/提示，共 202 个语音描述符；保留前八 ID 顺序。朗读摘要可比展示知识短，清单记录两者。
- [x] 图片：`assets/animations/dinosaurs40/` 中每种一张九格原图，前八格顺序动作，第九格复第一格。保留四十提示词、原图、模型/工具来源、预览和设备编码；检查主体一致、特征、裁切及腿部姿态变化，修复失败结果。
- [x] 模型：`main/dino_model.*` 及测试。四十首尾循环、64 位低四十位足迹、五页足迹、动作暂停/重播/退出和时钟；24 字节 V2 接受 16 字节 V1，不擦 NVS。
- [x] 播放：新增纯 `main/dino_animation.*`、生成资产 C、测试/转换器。144×88、八帧、每种共用十六色 RGB565 调色板，I4 解包到复用的 25,344 字节缓冲，目标帧间隔 125 毫秒；逐帧不重建整个页面。
- [x] 运行时/UI：`main/main.c`、`main/dino_ui.*`、运行时测试及真实 LVGL 渲染器。按键前推进旧状态时钟；长按上键退出动作；进入动作取消语音。资源读取在音频任务中，对照 64 字节身份头；缺失/错配资源时降级语音并保留浏览。文字完成后生成/检查全中文字库。
- [x] 构建：分区、根/main CMake、固件校验/归档及测试。保留 3 MB factory 和身份/Recovery；在 `0x35a000` 增加 `0x3a6000` 大小语音分区，注册刷写参数、合并镜像和匹配调试归档；兼容旧归档 schema。
- [x] 证据/交付：完整门禁、四十条/320 帧资产验证、真实 LVGL 全页/字形/内存检查、匹配 BIN/ELF/MAP/资源哈希、固件/源码包及项目记录。另获授权前，真机测试标为未执行。

## 操作约定

保留卡片、知识和猜题操作。营地在“继续”前增加动作；上下循环四十种，切换从第零帧且保留暂停；确定暂停/继续，长按确定从头重播并恢复播放，长按上键返回营地。足迹每页八种，上下首尾循环五页。动作页静音，并标为重建示意。

## 资源与迁移检查

四十种、各八帧 144×88 I4 需 2,027,520 字节，加 1,280 字节调色板，另计索引/代码。语音需适配 3,825,664 字节分区，含 64 字节头目标不超过 3.7 MB；以最终实际构建数据验收，计算预算不代表 RAM/帧时序通过。

新合并镜像越过身份预留，填充可能重置身份与 NVS。真机需保留身份/数据时采用兼容分段写入，并先获授权；不生成身份或 Recovery 内容。

Project Pulse 状态是本地生成物，仅忽略其未跟踪输出路径；已跟踪和其他未忽略文档继续常规仓库/秘密检查，保留现有生成文件。
