# 亲子共创参考与 40 种恐龙增量

## 来源与目的

2026-10-02 用户提供了二年级孩子与家长制作奥特曼动态图鉴的文章正文。
[原文章](https://mp.weixin.qq.com/s/nAgYftdVR1To3E2gBON89g)此前停在网页验证，
现在可以根据正文核对流程与按键行为。链接中的实物照片、GIF 和社区发布
状态未独立核验。

作者关注孩子参与提出目标、比较版本、解释具体问题、修改任务和检查
结果；复杂工具与设备操作由家长负责。保留看得见的决定与反馈过程，
让孩子有时间选择、比较并说明发生了什么变化。

## 参考流程

1. 从孩子喜欢的主题开始，先做能操作的小规模卡通原型。
2. 比较结果。照片叠加光效阶段发现人物姿势与移动光线不协调，具体观察
   推动下一次修改。
3. 使用连续动作素材，同时核对主体与动作。示例选择 4.2 秒、每秒 10 帧
   得到 42 帧，再缩小压缩供离线播放。
4. 先做两个代表样片，检查动作并确定方向后扩展。最终 37 位角色是文章
   自身的内容规模。
5. 电脑预览与真机启动、显示、按键分别检查。作者报告白屏闪烁经 1.3.1
   修复，不代表恐龙护照已经通过真机验收。

## 范围决定与历史候选

最初恐龙护照构建包含八张静态插画和四十二段语音。随后文档曾提出
霸王龙、三角龙两个动作样片，并从营地进入独立静音页。初步候选采用
144×88、42 帧、16 色调色板及复用的 25,344 字节 RGB565 缓冲；两段估算
为 532,288 字节。这是预算计算，不是已实现功能或实测运行结果。

用户随后明确授权直接完成全部 40 种恐龙，要求 Image2 素材和动作，并
保留知识、语音和猜题。此授权已替代两个样片候选，不再等待只做两种的
确认；它不包括刷机、提交、推送或发布授权。

当前增量因此以 40 种、80 条知识、40 道观察题、202 段讲解、五页足迹和
每种八帧动作为范围。源素材请求指定 `gpt-image-2`，宿主工具不暴露实际
模型 ID，见[生成计划](../assets/animations/dinosaurs40/generation-plan.json)
及[来源与格式说明](../assets/animations/dinosaurs40/README.zh_CN.md)。
原八张图和四十二段语音保留为历史资料。

## 按键与有意保留的差异

| 行为 | 文章图鉴 | 40 种动作观看页 |
| --- | --- | --- |
| 画面 | 名字、连续动作、年代 / 绝技 | 名字和生成行走示意，知识卡仍有年代 / 食性 / 特征 |
| 上 / 下 | 前后角色、首尾循环 | 前后 40 种恐龙、首尾循环 |
| 单击确定 | 暂停 / 继续 | 暂停 / 继续 |
| 长按确定 | 从头重播并继续 | 第零帧重播并继续 |
| 切换 | 从头，保留暂停 / 播放状态 | 从头，保留暂停 / 播放状态 |
| 退出 | 所提供片段未明确 | 长按上键返回营地 |
| 声音 | 无 | 动作页静音，知识页保留可关闭讲解 |
| 其他活动 | 动作观看 | 保留知识、猜题、提示和足迹闭环 |

营地独立入口避免改变知识卡上确定键的含义。八帧动作和模型 125 毫秒
间隔的目标是每秒八帧。文章中的 42 帧和 10 fps 是示例，不是必须照搬的
参数；实际 Passport 帧时序仍待测量。

## 示意与验收边界

这些史前恐龙没有真实活体影像。生成图集是行走插画示意，不是经过科学
验证的步态复原。原图集和提示词保留；转换裁出前八个完整格子，再缩放
并量化共享调色板，不生成中间动作。帧数据不同只能证明图像不同，不能
证明步态可信、形态准确、接缝顺滑或设备帧率。

电脑 PNG/GIF 预览与真实 LVGL 宿主截图帮助比较版本，不标作设备照片、
录像或实测设备帧率。可以让孩子观察特征是否清楚、脚步是否协调、全身
是否完整、循环是否突然跳动；把分歧变成具体的下一次观察，不变成评分。

40种实现与素材已完成，完整门禁与匹配固件/资源归档已通过；另行授权的
真机验收单独记录。全帧、操作、字形、重复导航、存档迁移与资源身份已
离线检查；获得单独授权后再检查板上启动、颜色、实际帧时序、按键、声音、
内存及数据。见[使用指南](dinobook.zh_CN.md)与[精确验证证据](dinobook40-validation.zh_CN.md)。
参考文档不替代当前已验证制品，也不代表刷机许可。
