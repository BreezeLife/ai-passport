# 恐龙护照使用与真机验收

完整40种恐龙版本包含80条知识、40道双选观察题、202段普通话
开发语音及独立动作观看页。所有恐龙从一开始都可查看。答错提供提示和
再次尝试，不设分数或惩罚。本指南记录实现与资源约定，完整构建及主机检查
已通过；精确构建证据以[验证记录](dinobook40-validation.zh_CN.md)为准。

[亲子参考比较](dinobook-reference.zh_CN.md)说明用户提供的文章，以及随后
直接完成全部 40 种的授权。动作是 AI 生成的行走插画示意，不是活体实拍、
经过科学验证的运动复原或设备录像。

## 操作

封面按确定开始。上下首尾循环查看 40 张恐龙卡，确定进入第一条知识。
知识页上下切换两条知识和猜题入口；确定重听知识或开始问题。上下选择
答案，确定提交。答错给提示，确定重试；答对收集足迹，确定展示印章，
再确定发现下一只。长按确定返回恐龙卡；在卡上长按确定进入营地。

营地包含足迹、声音、动作观看和继续发现。足迹册有五页，每页八种恐龙，
上下首尾循环翻页，确定返回当前恐龙卡。声音可关闭，音频不可用时仍可
继续浏览。

| 动作页操作 | 结果 |
| --- | --- |
| 上 / 下 | 首尾循环切换恐龙，重置到第零帧，保留暂停 / 播放状态 |
| 单击确定 | 暂停或继续 |
| 长按确定 | 从第零帧重播并恢复播放 |
| 长按上键 | 返回营地 |

动作观看页静音。每种恐龙有八帧 144×88 索引图；模型按每帧 125 毫秒调度，
目标为每秒八帧。这是配置间隔，不是实测设备帧率。主机预览和 GIF 来自
电脑，GIF 按百分之一秒计时，以 120/130 毫秒交替。见[动作来源与转换](../assets/animations/dinosaurs40/README.zh_CN.md)。

## 存档与资源

独立 `dinobook` NVS 命名空间保存足迹、声音偏好和当前恐龙。V2 是带 CRC32
的 24 字节记录，包含 64 位足迹字段，只有低 40 位有效。旧 V1 必须恰为
16 字节，并通过标识、版本、预留字节、声音值、原八种范围内的选择及 CRC
检查才可迁移。前八种保留原顺序，因此已有足迹含义不变。后续正常保存
写入 V2，读取不会立刻改写记录。暂停状态、帧、页面等临时观看状态不保存。

写入合并等待 700 毫秒，立即断电可能丢失最后一次变化。损坏或不支持的
记录回退默认值；未知读取失败停用本次启动的写入，不清空共享 NVS。
音频和存档失败仍显示告警，导航保持可用。

音频、电量和存储由工作任务处理，按键回调只入队。语音为原语速 155 的
8 kHz 单声道 IMA ADPCM，显示知识比独立朗读摘要更完整。普通 Tingting
系统合成声音属于开发语音，音量暂设 35%，待扬声器验收。播完或取消后
休眠 codec。闲置 45 秒调暗、90 秒关背光，首次按键只唤醒；这不代表已测
深度休眠功耗。

应用保留 3 MB factory 槽、`0x356000` 身份预留、`0x700000` Recovery 区域及
上键五秒启动钩子。独立 `dino_audio` 数据分区从 `0x35a000` 开始，当前
`assets/audio/dinobook40/audio.bin`为 3,200,798 字节，包含
64 字节身份头。固件播放前比较身份头及预期大小，失配则停用讲解。这只
将资源绑定到应用构建，不会在运行时校验整个载荷；离线[音频验证器](../assets/audio/README.zh_CN.md)
检查完整载荷。此前八张静态图和四十二段语音保留为历史，不链接进 40 种
版本应用。

## 固件交付与真机验收

在 ESP-IDF 5.5.3 下运行 `./tools/validate.sh`，并用
`python3 tools/archive_firmware.py verify <archive-directory>` 核验精确归档。
归档必须包含匹配的外部音频资源。真实 LVGL 主机渲染检查字形、排版和
重复导航，其截图来自电脑，不是设备实拍。构建、宿主结果与真机结果须
分别报告。

从 `0x0` 刷合并镜像虽然不含身份或 Recovery 载荷，整段写入中的 `0xFF`
填充间隙仍可能擦除已有 NVS 和设备身份。需要保留身份及进度时，采用
兼容的分段刷写，仅在指定地址写 bootloader、分区表、应用和音频。两种
路径都需要单独的硬件授权。空白设备需另行配置兼容身份和 Recovery。
不需要例行全片擦除或读取原固件。

另行授权后检查：无 panic 或反复重启；40 种及全中文页面；形态、全身构图、
调色板颜色、循环接缝和实际帧时序；动作切换、暂停、继续、重播及长按上键
返回；知识操作和五页足迹；读音、清晰度、音量、削波及音频取消；重启后
进度与 V1 迁移；可选资源及外设失败；背光唤醒；空闲堆、最大连续块、
栈和长时间稳定性；以及已配置兼容 Recovery 设备的启动入口。未执行前，
这些真机项目仍属未验证。
