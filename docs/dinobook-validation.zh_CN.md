## 应用检查

- 模型：17/17 测试、4,096 种存档状态往返、单比特损坏及正确 CRC 下非法字段拒绝、262,144 次输入转换。模型与 ADPCM 解码器另通过 ASan/UBSan。
- 真实 `main.c`：严格 C11、告警视为错误，20 个确定性故障场景通过。覆盖 UI 锁失败后重绘；NVS 初始化/读取/写入/提交故障且不擦除；8 kHz 音频、取消/替换及静音启动；任务/按键/队列分配失败；codec 初始化/唤醒/写入失败。可选队列失败仍可浏览与闲置关屏。
- 字库：14/18/24 px 各覆盖当前所需 413 字符；缺失的 U+9F98 负向探针拒绝。保留来源、OFL 许可及生成清单。
- 音频：42 段哈希、文本、描述符、参考编码及真实 C 解码校验通过；压缩后 1,167,929 字节，总时长 291.979125 秒。未播放到扬声器。
- 素材：八张原创生成插画保留提示词、原始/转换哈希及 RGB565 数据；知识库保留博物馆引用，语音明确标识为系统开发讲解。
