Comparing the 64-byte audio header detects resource identity mismatch, not arbitrary payload corruption at runtime; build/archive verification hashes the whole resource.
- Speech is 8 kHz mono IMA ADPCM to fit the 3 MB application slot without speeding up the narration. The audio worker sets the codec to that exact rate, interrupts between PCM chunks and suspends it after playback. System voice provenance is recorded; physical pronunciation and audio quality remain open.
- First-frame rendering uses an 8 KB main stack and a 48 KiB LVGL pool. Optional audio/storage queue or worker allocation failure degrades those functions while browsing remains available. Persist UI dirtiness across lock timeouts. NVS read errors disable the writer instead of replacing unknown records.
